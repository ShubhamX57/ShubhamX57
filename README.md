### Projects

- **[kappa-kinisi](https://github.com/ShubhamX57/kappa-kinisi)** · MSc dissertation. Found why a small fraction of [kinisi](https://github.com/kinisi-dev/kinisi) diffusion fits go wrong (14 of 64,000), traced each one to a single eigendirection of the covariance matrix, and designed an adaptive eigenvalue floor that fixes them without changing healthy fits.
- **[qens](https://github.com/ShubhamX57/qens)** · Bayesian analysis of quasi-elastic neutron scattering data from ISIS `.nxspe` files: joint fit across all Q-bins, MCMC with convergence checks, and a plug-in model registry. [Docs](https://qens.readthedocs.io/en/latest/)
- **[nxcat](https://github.com/ShubhamX57/nxcat)** · A small metadata catalogue for neutron data: NeXus ingest, FastAPI, React and TypeScript, PostgreSQL search, and a plain-English search where the AI can only suggest a filter that the user confirms.
- **[scisolve](https://github.com/ShubhamX57/scisolve)** · A numerical solver where every number in an answer must come from code run in the same session, and every answer names the check it passed.
- **[arxiv-rag](https://github.com/ShubhamX57/arxiv-rag)** · A retrieval system over research papers, where every answer quotes its source or declines.
